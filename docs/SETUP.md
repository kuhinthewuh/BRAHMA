# BRAHMA Setup

## ONLY THINGS THE HUMAN MUST DO

1. Add `OPENAI_API_KEY` to `.env`
2. Add `DAYTONA_API_KEY` to `.env`
3. Add `BRAHMA_MODE=live` to `.env` (Required for TrueForge presentation mode)
4. Confirm Qodo GitHub app is installed on this repository

All other dependencies and configuration are automated. Run `npm run doctor` to verify setup.
